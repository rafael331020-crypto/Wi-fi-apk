# Wi-Fi Scanner — estudo

Aplicativo Android educacional para listar redes Wi-Fi próximas e exibir informações disponibilizadas pelo Android, como SSID, intensidade do sinal, frequência/canal e tipo de segurança.

## Uso responsável

O aplicativo realiza apenas descoberta passiva das redes anunciadas pelo dispositivo. Não tenta obter senhas, explorar vulnerabilidades, quebrar autenticação ou acessar redes sem autorização.

## Compilação

O projeto foi preparado para ser compilado pelo GitHub Actions e gerar um APK de debug como artefato.
